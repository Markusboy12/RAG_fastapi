## 🔑 ШАГ 1: НАСТРОЙКА API КЛЮЧЕЙ

### 1.1 Скопируйте шаблон .env
```bash
cd /workspace
cp .env.example .env
```

### 1.2 Получите бесплатные API ключи

| Сервис | URL | Free Tier |
|--------|-----|-----------|
| **Groq** (LLM) | https://console.groq.com | ~200 запросов/день |
| **Voyage AI** (Embeddings) | https://dashboard.voyageai.com | 200K токенов/месяц |
| **Qdrant** (Vector DB) | https://cloud.qdrant.io | 1 ГБ бесплатно |
| **Redis** (Memory) | https://redis.com/try-free | 30 МБ бесплатно |
| **Firecrawl** (Парсинг) | https://www.firecrawl.dev | 500 стр/мес (опционально) |

### 1.3 Заполните .env файлик
```bash
nano .env  # или vim, code, любой редактор
```

Минимально необходимые поля:
```env
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxx
VOYAGE_API_KEY=xxxxxxxxxxxxxxxxxxxx
QDRANT_URL=https://your-cluster.qdrant.tech
QDRANT_API_KEY=xxxxxxxxxxxxxxxxxxxx
REDIS_URL=redis://your-redis-url:6379
```

## 📚 ШАГ 3: ИНДЕКСАЦИЯ ДОКУМЕНТАЦИИ

Перед первым запуском нужно загрузить документацию FastAPI в Qdrant:

```bash
# Активация виртуального окружения (если используется uv)
source .venv/bin/activate  # Linux/Mac

# Запуск индексера
python -m backend.indexer
```

**Важно:** Для автоматической загрузки через Firecrawl нужен `FIRECRAWL_API_KEY` в `.env`.

Если Firecrawl ключа нет:
1. Скачайте markdown файлы вручную с https://fastapi.tiangolo.com
2. Положите в папку `/workspace/data/`
3. Отредактируйте `backend/indexer.py` для загрузки из файлов

## 🏗️ АРХИТЕКТУРА RAG ПАЙПЛАЙНА

```
User Query ("как сделать JWT авторизацию")
    ↓
[HyDE] Groq генерирует гипотетический код с OAuth2PasswordBearer + JWT
    ↓
[Embed] Voyage AI voyage-code-3 → вектор гипотетического кода
    ↓
[Retrieve] Qdrant hybrid search → top-5 чанков из docs.fastapi.dev
    ↓
[Grade] фильтрация чанков по relevance score (>0.5)
    ↓
[Assemble] чанки + последние 5 сообщений из Redis
    ↓
[Generate] Groq qwen-3-27b (streaming) → ответ с примером кода
    ↓
[SSE Stream] → браузер посимвольно
    ↓
[Save] вопрос + ответ → Redis (memory)
```

## 🔧 TROUBLESHOOTING

### ❌ "ModuleNotFoundError: No module named 'backend'"
```bash
# Запускайте из корня проекта
cd /workspace
export PYTHONPATH=/workspace:$PYTHONPATH
```

### ❌ "FIRECRAWL_API_KEY не настроен"
- Либо получите ключ на https://www.firecrawl.dev
- Либо загрузите документы вручную (см. Шаг 3)

### ❌ "Redis connection failed"
- Проверьте `REDIS_URL` в `.env`
- Убедитесь что Redis инстанс активен в панели управления

### ❌ "Qdrant collection not found"
- Запустите индексер: `python -m backend.indexer`
- Коллекция создастся автоматически при первом запуске

### ❌ SSE не работает в браузере
- Откройте консоль разработчика (F12)
- Проверьте на наличие CORS ошибок
- Попробуйте endpoint `/chat/sync` вместо `/chat`

### ❌ "No tokens in response"
- Проверьте GROQ_API_KEY
- Убедитесь что модель `qwen/qwen-3-27b` доступна
